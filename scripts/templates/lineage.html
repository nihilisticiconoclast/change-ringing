HOW TO READ THIS DIAGRAM
Red Line — The Treble (Hunt Bell 1):
The Treble weaves steadily between Column 1 (Lead / front) and Column N (Lie / back) and back to Lead, creating the structural rhythm of the method.
Blue Line — Working Bell (Bell 2):
The famous "Blue Line" memorized by bellringers. It traces how an inside working bell dodges, makes places, and navigates changes throughout the lead.
Columns 1 to N — Rope Striking Positions:
Each vertical column is a striking position in the row, numbered 1 (Lead / first to strike) to N (Lie / last to strike).
Hereditary Extension Principle:
When a method is extended to higher stages, the Front Work (positions 1–4) remains identical, while additional dodging cycles expand into the new back bell positions.
